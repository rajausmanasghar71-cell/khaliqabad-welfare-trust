# خالق آباد ویلفیئر ٹرسٹ — CMS Website

## اہم
یہ CMS ورژن تیار ہے، لیکن `admin/config.yml` میں `YOUR_GITHUB_USERNAME/YOUR_REPOSITORY` کو اپنے GitHub repository سے تبدیل کرنا ہوگا۔

### CMS کہاں کھلے گا؟
اپنی live ویب سائٹ کے آخر میں `/admin/` لگائیں:
`https://YOUR-SITE.netlify.app/admin/`

### کیا edit کیا جا سکتا ہے؟
- ٹرسٹ کا نام
- ابتدائی تعارف
- ہمارے بارے میں
- ہمارے کام
- Facebook لنک
- WhatsApp
- گیلری اور تصاویر

### موجودہ authentication
اس پراجیکٹ میں Decap CMS کا GitHub backend رکھا گیا ہے۔ اس کے لیے Netlify پر GitHub authentication/OAuth اور GitHub repository connection مکمل کرنا ضروری ہے۔
